# coldwar-esp

ESP + performance patch for **Cold War [VIETNAM]** on Roblox.

## Load

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fieyhqwis/coldwar-esp/main/esp.luau"))()
```

## What it does

- ESP corners for all players, color by team (PACT red / NATO blue)
- Range 800 studs, up to 20 boxes on screen, nothing else
- No text, no names, no health bars - pure corners
- Fog and atmosphere haze removed
- All post effects off: bloom, blur, sunrays, depth of field, color correction
- Shadows off, water flat
- Camera max zoom 400
- Graphics quality forced low - grass and extra detail gone, FPS up

## Notes

- No keybinds. Run it and it works.
- You are never drawn on your own ESP.
- Per-player HP is not replicated by this game, so there is no HP display.
